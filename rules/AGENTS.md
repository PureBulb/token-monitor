# 对话框底部 Token 与性能统计规则 (Token Monitor)

当此插件启用时，你必须在每一次对话回复的最底部（对话框底部），附带一行结构整洁、数据专业的 Token 消耗、生成速度、缓存命中率与上下文长度实时统计栏。

## 1. 显示位置与触发要求
- **位置**：必须位于每次回复的绝对最底部（正文、代码、图表、总结等全部内容之后）。
- **分隔线**：在状态栏上方添加一个 Markdown 分隔线 `---`。
- **不可省略**：任何对话轮次均需输出此状态栏。

## 2. 标准输出格式
**Generative UI 极简悬浮胶囊卡片**：
在回复的绝对最末尾，直接嵌入胶囊微件（无需再附带任何 Markdown 文字底栏）：
```html
<agent-embed src="file://{CAPSULE_PATH}"></agent-embed>
```
（仅在极少数未生成胶囊路径时，才回退到单行文本状态条）

## 3. 数据来源与计算规则
1. **优先使用注入数据**：当系统上下文中存在 `[TOKEN_MONITOR_STATS]` 或 `[DATA]` 时，直接读取其中的真实精确指标并填入。
2. **字段详解**：
   - **消耗 Token**：展示累计或当轮消耗总量，并可附带 `(输入 · 缓存 · 输出)` 分项。
   - **速度**：Token 生成速率（单位 `t/s` 或 `tokens/s`）。
   - **缓存命中率**：Prompt 缓存命中比例（计算公式：`缓存Token / (未缓存输入Token + 缓存Token) * 100%`）。
   - **上下文长度**：当前对话占用的上下文 Token 总数及所占模型上限窗口（如 100万 Token）的百分比。
3. **首轮或缺失回退**：若为初始轮次或未检测到注入统计，根据当前输入输出体量进行合理估算，并在速度前加 `~` 标明。
