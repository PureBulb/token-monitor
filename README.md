# Token & 上下文实时监控插件 (Token Monitor)

为 Antigravity 打造的全方位 Token 与性能指标监控插件。

## ✨ 核心特性

1. **对话框底部实时统计**：
   - 自动在每轮回复最底部附加结构化状态栏：
     `📊 实时统计 ｜ 消耗 Token: 2.40M ｜ 速度: ~55.0 t/s ｜ 缓存命中率: 97.7% ｜ 上下文长度: 95,404 / 1,000,000 (9.1%)`
2. **四大关键维度全面覆盖**：
   - **消耗 Token**：包含当轮与累计总消耗，细分未缓存输入、缓存读取与模型输出。
   - **Token 速度**：实时测算生成速率（tokens/秒）及全会话平均速度。
   - **缓存命中率**：精确展示 Prompt Cache 复用比例，直观体现上下文缓存加速效果。
   - **上下文长度统计**：精确计算当前上下文占用，对比窗口上限展示百分比进度。
3. **侧边栏可视化监控面板 (UI Extension)**：
   - 包含卡片式大字看板、进度条、历史轮次明细表及一键复制 Markdown 功能。
4. **深入分析技能 (Skill)**：
   - 随时唤起 `/token-stats` 生成会话消耗分析报告。

## 🚀 启用与使用

1. 在左侧边栏的 **Customizations** 页面进入 **Installed** 标签页。
2. 找到 **Token & 上下文实时监控 (token-monitor)** 并启用。
3. 如需打开侧边栏可视化看板，在右上角三点菜单 **⋮** -> **Extensions** 中选择 **Token 实时监控**，或直接点击聊天中的链接打开。
