# Token & 上下文全景监控插件 (Token Monitor)

为 Antigravity 打造的全功能 Token 监控、上下文走势与行为审计套件（深度集成并融合 dsh-context 全部核心能力）。

## ✨ 核心特性

1. **对话框底部 Generative UI 悬浮胶囊卡片**：
   - 极简悬浮胶囊设计，实时展示：总消耗 Token、模型生成速度、Prompt 缓存命中率（全会话平均优先）、当前上下文占用及 6 维分布微进度条。
   - 动态成本估算徽章（如 `💰 $58.28`），鼠标悬浮查看折合人民币金额、Prompt 缓存已省金额及计费基准模型。
2. **上下文趋势图表 (Context Trend Chart)**：
   - 完整记录从首轮到当前每一轮的上下文容量变动，SVG 动态折线与面积阴影图。
   - 智能识别历史压缩截断点（如 Billion-Context / ACP 压缩触发时刻），标记 📦 截断点并显示释放 Token 数量。
   - 鼠标悬浮查看各轮次精确 Token 数、环比增量及时间戳。
3. **文件操作审计追踪 (File Activity Tracker)**：
   - 深度审计智能体在会话中的全部文件行为（`view_file`、`write_to_file`、`replace_file_content`）。
   - 实时统计文件总数、读取次数、修改/创建次数、新增代码行数 `+N` 与删除代码行数 `-M`。
   - 提供按路径/文件名搜索、按「全部 / 已修改 / 仅读取」快速过滤。
4. **命令执行审计看板 (Command Executions Dashboard)**：
   - 深度审计所有终端命令（`run_command`），记录程序类别、完整命令行、执行耗时、轮次与退出状态（OK / ERR）。
   - 自动统计程序分布频次标签（如 `git: 45`, `ls: 32`, `curl: 14`, `npm: 8`），点击任一标签即可一键过滤。
5. **实时费用测算与缓存节省评估 (Cost & Savings)**：
   - 支持多模型计费预设切换（Gemini 1.5 Pro、Gemini 1.5 Flash、Gemini 2.0 Flash、Claude 3.5 Sonnet）。
   - 自动按未缓存输入、缓存读取（享折扣）、模型输出精确计算总消耗费用（美元 USD 与折合人民币 CNY）。
   - 显式量化展示 Prompt Cache 累计节省的实际金额。
6. **上下文 6 维构成分类 (Context Breakdown)**：
   - 全面细分为 6 大构成部分：工具调用与执行输出（紫）、系统提示与规则（蓝）、深度思考与推理（青灰）、模型回答输出（青）、用户输入指令（绿）、历史压缩摘要（橙）。
   - 侧边栏提供多彩分段进度条与交互式六格图例。
7. **多标签页侧边栏控制台 (UI Extension)**：
   - `📊 实时概览` | `📈 上下文趋势` | `📁 文件审计` | `⚡ 命令审计` | `🕒 轮次明细`
   - 支持一键复制格式化 Markdown 状态底栏，便于分享与留档。

## 🚀 启用与使用

1. 在左侧边栏的 **Customizations** 页面进入 **Installed** 标签页。
2. 找到 **Token & 上下文实时监控 (token-monitor)** 并启用。
3. 在右上角三点菜单 **⋮** -> **Extensions** 中选择 **Token 实时监控** 打开侧边栏全景看板。
